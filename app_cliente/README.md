## Lo que necesitas para ejecutar el proyecto

- Tener instalado flutter en tu computadora
- Utilizar los siguiente comandos para instalar las dependencias y ejecutar posteriormente 
- Instala las dependencias con el comando *flutter create .* 
- Añade tu API key DE google maps en el archivo .env
- Verifica que todas las dependencias estén instaladas
- Crea la base de datos y verifica que estén presente todas las tablas
- Verifica la conexión emulador/pc
- Levanta el emulador o conecta tu pc a un dispositivo móvil
- Utiliza el comando *flutter run* para ejecutar el proyecto
- Explora el proyecto
